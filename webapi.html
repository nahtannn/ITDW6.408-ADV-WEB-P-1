JSON Rules

Data Types

JSON supports six data types: String, Number, Object, Array, Boolean, and null. Each data type has its own rules and syntax. 

{
    "String": "Hello, World!",
    "Number": 42,
    "Object": {
        "key": "value"
    },
    "Array": [1, 2, 3],
    "Boolean": true,
    "null": null
}

Object Structure

Objects are unordered sets of key/value pairs. Each key is a string, and each value can be any valid JSON data type. Objects are enclosed in {}. 

//This code is a valid JSON object.
{
    "name": "John Doe",
    "age": 30
}
//This code is an invalid JSON object 
//as it is missing the comma seperating the keys
{
    name: "John Doe"
    age: 30
}

Array Structure

Arrays are ordered lists of values. Each value can be any valid JSON data type. Arrays are enclosed in []. 

{
    //This code is a valid JSON array using strings
    "providers": ["OneNZ", "2Degress", "Skinny"]

    //This code is a valid JSON array using numbers
    "numbers": [1, 2, 3, 4, 5]

    //This code is an invalid JSON array 
    //as it is using curly brackets 
    "invalidArray": {1, 2, 3, 4, 5}
}

Key Rules

Keys must be strings enclosed in double quotes. 

{
    //This code is a valid JSON object
    "validKey": "value"

    //This code is an invalid JSON object
    //as the key is not enclosed in double quotes
    invalidKey: "value"

    //This code is an invalid JSON object
    //as the key is enclosed in single quotes
    'invalidKey': "value"
}

String Formatting

Strings must be enclosed in double quotes. Special characters must be escaped using a backslash (\). 

{
    //This code is a valid JSON string
    "path": "C:\\Users\\Nat\\Documents\\AdvWebsite",
    "quote": "\"I think therefore I am.\"- Descartes"

    //This code is an invalid JSON string
    //as the special character is not escaped
    "path": "C:\Users\Nat\Documents\AdvWebsite",
    "quote": ""I think therefore I am."- Descartes"
}

Syntax/punctuation

JSON does not allow trailing commas and/or comments. (comments in my examples are for demonstration purposes) 

{
    //This code is a valid JSON object
    "name": "John Doe",
    "age": 30

    //This code is an invalid JSON object
    //as it has a trailing comma and a comment
    "name": "John Doe", //Invalid Comment
    "age": 30,
}
